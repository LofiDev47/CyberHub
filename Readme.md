## CyberHub 
the cyberpunk (kinda) themed USB hub

![Alt text](https://github.com/LofiDev47/CyberHub/blob/main/screenshot_2026-07-24_11-52-21.png?raw=true)

It has 5 USB ports 
with 1 type-c to connect to the computer
and 3 USB-a and 1 USB-c for the peripherals
all being drive by the CoreChips SL2.1s Usb 2 chip
